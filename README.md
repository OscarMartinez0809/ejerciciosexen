\# ejerciciosexen



Este repositorio contiene una colección de ejercicios prácticos en \*\*Java\*\*, desarrollados como parte del módulo de sexenios. Cada archivo aborda un tema específico de programación, incluyendo estructuras de control, validación, operaciones matemáticas y manipulación de datos. Todos los programas son independientes y pueden ejecutarse por separado.



\## 📂 Archivos incluidos



| Archivo                        | Descripción breve                                 |

|-------------------------------|----------------------------------------------------|

| BusquedaNumero.java           | Busca un número dentro de un arreglo               |

| CalculadoraArea.java          | Calcula el área de figuras geométricas             |

| Clase19.java                  | Ejercicio libre del día 19                         |

| ClasificadorCalificaciones.java | Clasifica calificaciones en rangos                |

| ContadorVocales.java          | Cuenta vocales en una cadena de texto              |

| ConversorUnidades.java        | Convierte entre distintas unidades                 |

| GeneradorSecuencia.java       | Genera secuencias numéricas                        |

| InversorArreglo.java          | Invierte el orden de un arreglo                    |

| OperacionesMath.java          | Realiza operaciones matemáticas básicas            |

| PromedioDinamico.java         | Calcula promedio de valores ingresados dinámicamente |

| SumaRangos.java               | Suma números dentro de un rango                    |

| ValidarContrasena.java        | Verifica si una contraseña cumple criterios         |
